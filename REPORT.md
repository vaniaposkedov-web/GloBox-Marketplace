# Отчёт о проделанной работе

## ✅ Что сделано

### 1. Страница профиля (`/profile`)
- Тёплый градиентный хедер, аватар с инициалами
- Отображение роли, статуса верификации, даты регистрации
- Редактирование имени, фамилии и аватара с Zod-валидацией
- Карточки статистики: корзина, избранное, заказы
- Быстрые ссылки: заказы, избранное, корзина, смена пароля
- Кнопка выхода

### 2. Вход по email с кодом подтверждения
- **Шаг 1**: ввод email + пароль → отправка кода на почту
- **Шаг 2**: ввод 6-значного кода → проверка код + пароль → JWT
- Бэкенд: `POST /api/auth/login/email/request-code`, `POST /api/auth/login/email/verify`

### 3. Вход по телефону с SMS-кодом
- **Шаг 1**: ввод телефона + пароль → отправка SMS-кода
- **Шаг 2**: ввод 6-значного кода → проверка код + пароль → JWT
- Бэкенд: `POST /api/auth/login/phone/request-code`, `POST /api/auth/login/phone/verify`
- Убран текст «Отправим код по SMS — пароль не нужен»
- Добавлено поле пароля

### 4. Авторизация через VK (OAuth 2.0)
- Бэкенд-сервис `VkOAuthService` — обмен code → access_token → профиль → JWT
- Эндпоинты: `GET /api/auth/vk/auth-url`, `POST /api/auth/vk/callback`
- Фронтенд: реальный редирект на VK OAuth (вместо заглушки)
- Callback-страница `/auth/vk/callback` — обрабатывает возврат от VK
- Автосоздание пользователя или привязка VK к существующему аккаунту по email

### 5. Сервис SMS-кодов
- `SmsCodeService` — генерация, хэширование (argon2), проверка, TTL 5 мин, 3 попытки
- Модель `SmsCode` в Prisma
- Enum `LOGIN_VERIFICATION` добавлен к `EmailCodePurpose` и `SmsCodePurpose`

### 6. Shared-пакет
- Новые Zod-схемы для login email/phone code потоков
- Пересобран, TypeScript ошибок нет

### 7. Общее
- Бэкенд (`apps/api`): `tsc --noEmit` ✅ — 0 ошибок
- Фронтенд (`apps/web`): `tsc --noEmit` ✅ — 0 ошибок
- Prisma Client пересгенерирован

## 📋 Что нужно сделать вам

### 1. Настроить VK OAuth

#### Шаг 1: Зайдите в VK для разработчиков
👉 **https://dev.vk.com/**

#### Шаг 2: Создайте приложение
1. Нажмите **«Мои приложения»** → **«Создать»**
2. Выберите **«Сайт»**
3. Заполните:
   - **Название**: Marketplizzzz (или ваше)
   - **Платформа**: Сайт
   - **Адрес сайта**: `http://localhost:3000` (на dev) или ваш домен на проде
   - **Базовый домен**: `localhost` (на dev) или ваш домен
4. Нажмите **«Подключить сайт»**

#### Шаг 3: Настройте Redirect URI
1. В настройках приложения → вкладка **«Настройки»**
2. В поле **«Авторизованный redirect URI»** добавьте:
   ```
   http://localhost:3000/auth/vk/callback
   ```
   На проде замените на:
   ```
   https://ваш-домен.ru/auth/vk/callback
   ```

#### Шаг 4: Скопируйте данные
На странице настроек найдите:
- **ID приложения** — это `VK_CLIENT_ID`
- **Защищённый ключ** — это `VK_CLIENT_SECRET`

#### Шаг 5: Вставьте в `.env`
В файле `apps/api/.env` (скопируйте из `.env.example` если нет):
```env
VK_CLIENT_ID=12345678
VK_CLIENT_SECRET=abcdef1234567890abcdef
VK_REDIRECT_URI=http://localhost:3000/auth/vk/callback
```

### 3. SMS-шлюз: рекомендации

#### 🏆 Лучший бюджетный вариант: **SMS.RU**

**Сайт**: https://sms.ru

**Почему SMS.RU:**
- **Бесплатно**: 5 бесплатных SMS в день (идеально для разработки)
- **Дёшево**: от **0.45₽ за SMS** на платном тарифе
- **Простой API**: один HTTP-запрос для отправки
- **Нет абонентской платы** — платите только за отправленные SMS
- **Есть тестовый режим** — отправка без реальной доставки
- **Быстрая регистрация** — без менеджеров и договоров

**Как подключить:**
1. Зарегистрируйтесь на https://sms.ru
2. Перейдите в **«API»** → скопируйте **api_id**
3. Скиньте мне `api_id` — я интегрирую в проект

**Пример запроса (для понимания):**
```
https://sms.ru/sms/send?api_id=YOUR_API_ID&to=79261234567&msg=Ваш+код:+123456&json=1
```

#### Альтернативы:

| Сервис | Цена за SMS | Особенности |
|--------|-------------|-------------|
| **SMS.RU** 🏆 | от 0.45₽ | 5 бесплатных/день, нет абонентки |
| **SMSC.ru** | от 0.75₽ | Давно на рынке, надёжный |
| **SMS Aero** | от 0.60₽ | Хороший API, есть SDK |
| **Twilio** | ~5₽ | Международный, дорого для РФ |

**Моя рекомендация**: начните с **SMS.RU** — бесплатный тариф для разработки, потом по 0.45₽ за SMS на проде.

### 4. MAX (max.ru) — пошаговая инструкция создания бота

MAX авторизация работает через бота в мессенджере MAX.
Весь код уже написан. Осталось создать бота на платформе MAX.

> **Важно:** Создание бота доступно только для **ИП или юрлиц** (резиденты РФ).
> Самозанятым и физлицам пока недоступно.

---

#### Шаг 1: Зайдите на платформу MAX для бизнеса

👉 Откройте **https://business.max.ru/self**

- Если впервые — введите номер телефона (лучше корпоративный)
- Придёт SMS-код — введите его
- Вы окажетесь в личном кабинете

---

#### Шаг 2: Создайте организацию

1. Платформа попросит ввести **ИНН** (10 цифр для юрлица, 12 для ИП)
2. Нажмите **«Далее»** → **«Создать»**
3. Следуйте инструкциям на экране

---

#### Шаг 3: Пройдите верификацию

Нужно подтвердить, что организация реально существует.
Есть **3 способа** (выберите удобный):

- **Госуслуги** — вход как Руководитель, нужна ЭЦП
- **Alfa ID** — через Альфа-банк
- **Т-Business ID** — через Т-Банк (Тинькофф)

После верификации вы получите доступ к созданию ботов.

---

#### Шаг 4: Создайте чат-бота

1. В личном кабинете перейдите в раздел **«Чат-боты»**
2. Нажмите **«Создать»**
3. Заполните карточку бота:
   - **Название**: `Marketplizzzz Авторизация` (или ваше)
   - **Логотип**: любое изображение 500x500 px (jpg/png, до 5 МБ)
   - **Описание**: `Бот для авторизации на сайте Marketplizzzz`
   - **Сайт**: `https://marketplizzzz.ru` (необязательно)
4. Нажмите **«Создать»**

> Ник бота сгенерируется автоматически по шаблону `idВАШ_ИНН_bot`
> Например: `id1234567890_bot`

---

#### Шаг 5: Дождитесь модерации

Бот уйдёт на модерацию. Уведомления о статусе придут в MAX от бота **«MAX для бизнеса»**.

Модерация обычно занимает **1–2 рабочих дня**.

---

#### Шаг 6: Получите токен бота

После прохождения модерации:

1. Зайдите в карточку бота на платформе
2. Перейдите в раздел **«Интеграция»**
3. Нажмите **«Получить токен»**
4. Скопируйте токен

---

#### Шаг 7: Скиньте мне 2 значения

Мне нужны:
- **Токен бота** — длинная строка вида `abc123...xyz` → это `MAX_BOT_TOKEN`
- **Ник бота** (без @) — например `id1234567890_bot` → это `MAX_BOT_USERNAME`

Я впишу их в `.env` — и авторизация через MAX заработает.

---

#### Как это будет работать для пользователя:
1. На сайте нажимает **«Продолжить через MAX»**
2. Открывается бот в MAX
3. Нажимает **«Поделиться контактом»**
4. Сайт автоматически залогинит пользователя (без пароля)
