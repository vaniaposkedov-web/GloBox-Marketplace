# Загрузка документов посредника

## Какие файлы добавить

| Имя файла     | Содержимое                              | Требования                          |
|---------------|-----------------------------------------|-------------------------------------|
| `passport.jpg` | **Разворот паспорта** (стр. 2–3 с фото) | Все надписи читаемы, не обрезано    |
| `selfie.jpg`  | **Селфи с паспортом в руке**            | Лицо + разворот паспорта в кадре    |
| `pass.jpg`    | **Пропуск из Садовода**                 | Данные и срок действия читаемы      |

## Форматы
- JPG, JPEG, PNG — все подходят (скрипт отправит как JPEG)
- Максимальный размер: **12 МБ** на файл
- Минимальное разрешение: **1000×700 px** (чтобы текст был читаем)

## Как загрузить

1. Добавь три файла в эту папку (`upload-docs/`)
2. Открой `upload.js` и заполни:
   ```js
   const EMAIL    = "твой@email.com";
   const PASSWORD = "твой_пароль";
   ```
3. Запусти из корня проекта:
   ```
   node upload-docs/upload.js
   ```
4. Скрипт войдёт в аккаунт, загрузит фото и отправит заявку на проверку.
