# GloBox Marketplace

## Быстрый старт (Windows)

### Шаг 1. Установка (один раз)
```
Правой кнопкой по setup.bat → Запуск от имени администратора
```
Скрипт автоматически установит Node.js, pnpm, PostgreSQL, зависимости, создаст базу и тестовые аккаунты.

### Шаг 2. Запуск
```
Двойной клик по start-all.bat
```
Откроются 4 окна (по одному на сервис). Подождите ~15 секунд пока всё загрузится.

### Шаг 3. Остановка
```
Двойной клик по stop-all.bat
```

## Требования (всё ставится автоматически через setup.bat)
- Windows 10/11
- Интернет (для скачивания)

## Структура проекта
```
marketplace/
  apps/
    api/        — NestJS бэкенд (порт 4000)
    web/        — Покупатель, Next.js (порт 3000)
    seller/     — Кабинет поставщика (порт 3001)
    admin/      — Админ-панель (порт 3002)
  packages/
    shared/     — Общие типы и DTO
  setup.bat     — Полная автоустановка
  start-all.bat — Запуск всех сервисов
  stop-all.bat  — Остановка всех сервисов
```

## Стек
- **Backend:** NestJS + Fastify + Prisma + PostgreSQL
- **Frontend:** Next.js 14 (App Router) + TailwindCSS
- **Авторизация:** JWT, ролевые guard'ы (BUYER / SUPPLIER / ADMIN)
- **Монорепо:** pnpm workspaces
