# Подключение SMS и Email

## SMS — через SMS.RU

### Почему SMS.RU

| Критерий | SMS.RU | SMSC.ru | SMS Aero | Twilio |
|----------|--------|---------|----------|--------|
| **Цена за SMS** | **от 0.45₽** | от 0.75₽ | от 0.60₽ | ~5₽ |
| **Бесплатно** | **5 SMS/день** | нет | нет | нет |
| **Абонентская плата** | **нет** | нет | нет | есть |
| **Тестовый режим** | **да (test=1)** | да | нет | да |
| **Простота API** | **1 HTTP-запрос** | 1 запрос | SDK | SDK |
| **Регистрация** | **без менеджеров** | быстрая | с менеджером | долгая |

**Вывод:** SMS.RU — лучший вариант. Бесплатно для разработки, дёшево на проде, простейший API.

### Пошаговая настройка

#### Шаг 1: Регистрация

1. Откройте **https://sms.ru**
2. Нажмите **«Регистрация»**
3. Укажите email и телефон
4. Подтвердите email

#### Шаг 2: Получите api_id

1. Войдите в личный кабинет **https://sms.ru**
2. На главной странице найдите ваш **api_id** (длинная строка)
3. Скопируйте его

#### Шаг 3: Настройте .env

Откройте `apps/api/.env` и заполните:

```env
SMS_PROVIDER=smsru
SMS_API_KEY=ваш_api_id_из_sms_ru
SMS_TEST_MODE=true
```

- `SMS_PROVIDER=smsru` — включает реальную отправку через SMS.RU
- `SMS_API_KEY` — ваш api_id
- `SMS_TEST_MODE=true` — тестовый режим (SMS не отправляются, баланс не расходуется)

#### Шаг 4: Тестирование

С `SMS_TEST_MODE=true` SMS не отправляются реально, но API отвечает как при успешной отправке.
Это для отладки — баланс не тратится.

Когда готовы к реальной отправке:
```env
SMS_TEST_MODE=false
```

#### Шаг 5: Пополните баланс (когда нужно на проде)

1. В личном кабинете SMS.RU → **«Пополнить»**
2. Оплатите удобным способом
3. Минимальное пополнение — от 100₽ (это ~220 SMS)

#### Бесплатный лимит

SMS.RU даёт **5 бесплатных SMS в день** — этого хватит для разработки и тестирования.

## Email — через Яндекс SMTP

### Почему Яндекс

- **Бесплатно** — до 500 писем в день
- **Надёжная доставка** — письма не попадают в спам
- **Российские серверы** — быстро для РФ
- **Простая настройка** — SMTP с паролем приложения

### Пошаговая настройка

#### Шаг 1: Создайте или используйте почту Яндекс

Подойдёт любой ящик `@yandex.ru`. Если нет — зарегистрируйте на https://mail.yandex.ru

Рекомендую создать **отдельный** ящик для проекта, например:
```
marketplizzzz.noreply@yandex.ru
```

#### Шаг 2: Создайте пароль приложения

Обычный пароль от почты **не подойдёт** — Яндекс требует «пароль приложения».

1. Откройте **https://id.yandex.ru/security/app-passwords**
2. Нажмите **«Создать пароль приложения»**
3. Выберите тип: **«Почта»**
4. Придумайте название, например: `Marketplace SMTP`
5. Скопируйте сгенерированный пароль (показывается один раз!)

#### Шаг 3: Настройте .env

Откройте `apps/api/.env` и заполните:

```env
SMTP_HOST=smtp.yandex.ru
SMTP_PORT=465
SMTP_USER=marketplizzzz.noreply@yandex.ru
SMTP_PASS=сгенерированный_пароль_приложения
SMTP_FROM="Marketplace <marketplizzzz.noreply@yandex.ru>"
```

> **Важно:** В `SMTP_FROM` email должен совпадать с `SMTP_USER`!

#### Шаг 4: Перезапустите бэкенд

После заполнения `.env` перезапустите API — email начнут отправляться.

### Ограничения Яндекс SMTP

- До **500 писем в день** — для стартового проекта достаточно
- Если нужно больше — подключите Яндекс.Почту для домена (бесплатно, до 1000/день)

### Альтернативы (если нужно больше)

| Сервис | Бесплатный лимит | Цена |
|--------|-----------------|------|
| **Яндекс SMTP** 🏆 | 500 писем/день | бесплатно |
| **Mail.ru SMTP** | 500 писем/день | бесплатно |
| **Brevo (ex Sendinblue)** | 300 писем/день | от $9/мес |
| **Mailgun** | нет | от $0.80/1000 |
