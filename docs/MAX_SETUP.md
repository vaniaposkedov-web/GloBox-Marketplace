 и # Подключение авторизации через MAX (max.ru)

## Что такое MAX

MAX — российский мессенджер (max.ru). Авторизация на сайте работает через бота:
пользователь открывает бота в MAX, нажимает «Поделиться контактом», и сайт автоматически логинит его.

## Требования

- **ИП или юрлицо** (резидент РФ) — это требование платформы MAX
- Самозанятым и физлицам создание ботов недоступно
- Установленный мессенджер MAX (для тестирования)

## Пошаговая инструкция

### Шаг 1. Регистрация на платформе

1. Откройте **https://business.max.ru/self**
2. Введите номер телефона (лучше корпоративный)
3. Получите SMS-код и введите его
4. Вы попадёте в личный кабинет платформы MAX для бизнеса

### Шаг 2. Создание организации

1. Платформа попросит ввести **ИНН** вашей организации:
   - **10 цифр** — для юрлица (ООО, АО и т.д.)
   - **12 цифр** — для ИП
2. Нажмите **«Далее»** → **«Создать»**
3. Следуйте инструкциям на экране

### Шаг 3. Верификация организации

Нужно подтвердить, что организация реально существует.

**Способы верификации** (выберите один):

| Способ | Что нужно |
|--------|-----------|
| **Госуслуги** | Аккаунт руководителя + действующая ЭЦП |
| **Alfa ID** | Счёт в Альфа-Банке |
| **Т-Business ID** | Счёт в Т-Банке (Тинькофф) |

**Через Госуслуги:**
1. Нажмите «Подтвердить» → перейдёте на Госуслуги
2. Войдите как **Руководитель** (не сотрудник!)
3. Если к аккаунту привязано несколько организаций — выберите нужную
4. Подпишите согласие ЭЦП

**Через Alfa ID / Т-Business ID:**
1. Нажмите соответствующую кнопку
2. Авторизуйтесь в банке
3. Подтвердите организацию

После верификации вы получите доступ к созданию ботов.

### Шаг 4. Создание чат-бота

1. В личном кабинете перейдите в раздел **«Чат-боты»**
2. Нажмите **«Создать»**
3. Заполните карточку бота:

| Поле | Обязательно | Что указать |
|------|:-----------:|-------------|
| **Название** | Да | `Marketplizzzz` (или название вашего сайта) |
| **Логотип** | Да | Изображение 500×500 px, jpg/png, до 5 МБ |
| **Описание** | Да | `Бот для авторизации на сайте Marketplizzzz` |
| **Сайт** | Нет | `https://marketplizzzz.ru` |

4. Нажмите **«Создать»**

> **Ник бота** сгенерируется автоматически по шаблону `idВАШ_ИНН_bot`
> Например: `id7707049388_bot`

### Шаг 5. Модерация

После создания бот уходит на модерацию.

- Срок: **1–2 рабочих дня**
- Уведомления придут в MAX от бота **«MAX для бизнеса»**
- Статусы: «На проверке» → «Одобрен» или «Отклонён»

Если отклонили — исправьте замечания и отправьте повторно.

### Шаг 6. Получение токена

После одобрения:

1. Откройте **https://business.max.ru/self**
2. Перейдите в раздел **«Чат-боты»**
3. Нажмите на вашего бота
4. Перейдите во вкладку **«Интеграция»**
5. Нажмите **«Получить токен»**
6. Скопируйте токен (длинная строка)

> ⚠️ **Не передавайте токен посторонним!** Он даёт полный контроль над ботом.

### Шаг 7. Настройка проекта

Откройте файл `apps/api/.env` и заполните:

```env
MAX_BOT_TOKEN=ваш_токен_бота
MAX_BOT_USERNAME=idВАШ_ИНН_bot
```

Пример:
```env
MAX_BOT_TOKEN=abc123def456ghi789jkl012mno345pqr678stu901
MAX_BOT_USERNAME=id7707049388_bot
```

Перезапустите бэкенд — авторизация через MAX заработает.

## Как это работает для пользователя

```
1. На сайте нажимает «Продолжить через MAX»
           ↓
2. Открывается бот в мессенджере MAX
           ↓
3. Бот показывает кнопку «Поделиться контактом»
           ↓
4. Пользователь нажимает кнопку
           ↓
5. MAX отправляет номер телефона боту (с подписью)
           ↓
6. Бэкенд создаёт аккаунт или находит существующий
           ↓
7. Сайт автоматически залогинивает пользователя
```

Пользователю **не нужен пароль** — вход по подтверждённому номеру телефона из MAX.

## Архитектура (для разработчика)

### Бэкенд эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/auth/max/start` | Создать сессию, получить ссылку на бота |
| POST | `/api/auth/max/bot-callback` | Webhook от бота (контакт пользователя) |
| GET | `/api/auth/max/status/:sessionId` | Проверить статус (polling) |

### Файлы

| Файл | Описание |
|------|----------|
| `apps/api/src/modules/auth/telegram-auth.service.ts` | MaxAuthService — логика авторизации |
| `apps/api/src/modules/auth/auth.controller.ts` | Эндпоинты |
| `apps/web/src/features/auth-methods/ui/max-flow.tsx` | UI компонент |
| `apps/web/src/features/auth-methods/api.ts` | API вызовы |

### Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `MAX_BOT_TOKEN` | Токен бота из платформы MAX |
| `MAX_BOT_USERNAME` | Ник бота без @ (например `id7707049388_bot`) |

## FAQ

**Q: Можно ли тестировать без ИП/юрлица?**
A: Нет, создание бота на платформе MAX доступно только для ИП и юрлиц.

**Q: Сколько стоит?**
A: Создание бота и API бесплатно. Платформа MAX не берёт денег за ботов.

**Q: Как поменять домен при переезде на сервер?**
A: Ничего менять не нужно — авторизация через MAX не привязана к домену.
Просто перенесите `MAX_BOT_TOKEN` и `MAX_BOT_USERNAME` в `.env` на сервере.
