# Подключение SMS через SMSC.ru

## Что такое SMSC.ru

SMSC.ru (СМС-Центр) — российский сервис для отправки SMS-сообщений через HTTP API.
Используется в проекте для отправки одноразовых кодов подтверждения (OTP) при регистрации и смене пароля.

## Требования

- Аккаунт на **https://smsc.ru**
- Положительный баланс (от 50 ₽ для тестирования)
- Зарегистрированное **Имя отправителя** (sender ID), если нужно отправлять не от «SMSC.RU»

---

## Пошаговая инструкция

### Шаг 1. Регистрация

1. Откройте **https://smsc.ru/reg/**
2. Заполните форму: логин, пароль, ФИО, e-mail, телефон
3. Подтвердите e-mail
4. Войдите в личный кабинет

### Шаг 2. Настройки аккаунта

1. Перейдите в **Настройки** → вкладка **Аккаунт** (https://smsc.ru/edit/)
2. Убедитесь, что заполнены поля:
   - **Ваш логин** — это значение для `SMSC_LOGIN`
   - **Пароль** — это значение для `SMSC_PASSWORD`
   - **ФИО или Организация** — укажите название организации
   - **E-mail адреса** — для получения уведомлений
   - **Телефон** — контактный номер
3. **Валюта расчетов** — Российский рубль
4. **Баланс для уведомлений** — установите порог (например, 50 RUB), чтобы получать оповещение при низком балансе
5. **Часовой пояс** — GMT +03 Москва
6. **Имя отправителя (sender id)**:
   - По умолчанию стоит `SMSC.RU`
   - Для использования собственного имени (например, `Globox`) нужно зарегистрировать его (см. Шаг 4)
7. Нажмите **«Сохранить»**

### Шаг 3. Пополнение баланса

1. Перейдите в **Мой кабинет** → **Пополнить баланс**
2. Выберите удобный способ оплаты (карта, ЮMoney, банковский перевод)
3. Минимальная сумма — от 100 ₽
4. Стоимость 1 SMS ≈ 2–4 ₽ в зависимости от оператора

### Шаг 4. Регистрация имени отправителя (опционально)

Если хотите, чтобы SMS приходили от имени «Globox» вместо «SMSC.RU»:

1. Перейдите в **Настройки** → **Имена отправителей** (https://smsc.ru/senders/)
2. Нажмите **«Добавить»**
3. Введите желаемое имя (латиница, до 11 символов, например `Globox`)
4. Выберите тип: **Информационная рассылка** или **Транзакционные сообщения**
5. Прикрепите документы:
   - Свидетельство о регистрации ИП / выписка из ЕГРЮЛ
   - Скриншот сайта, откуда будут отправляться SMS
6. Ожидайте одобрения (обычно 1–3 рабочих дня)
7. После одобрения установите имя по умолчанию в **Настройки** → **Аккаунт** → **Имя отправителя**

### Шаг 5. Настройки API

1. Перейдите в **Настройки** → вкладка **API / SMPP**
2. Убедитесь, что доступ к HTTP API включён
3. Запомните свои учётные данные:
   - **Логин** — `SMSC_LOGIN`
   - **Пароль** — `SMSC_PASSWORD`

> **Безопасность:** Рекомендуется использовать **дополнительный пароль** для API.
> Создайте его на странице https://smsc.ru/passwords/ — это отдельный пароль,
> который используется только для API-запросов и не совпадает с основным паролем от кабинета.

### Шаг 6. Настройка переменных окружения

В файле `.env` на сервере (или `apps/api/.env` локально) укажите:

```env
# SMS провайдер — переключить на smsc
SMS_PROVIDER=smsc

# Учётные данные SMSC.ru
SMSC_LOGIN=ваш_логин
SMSC_PASSWORD=ваш_пароль_или_api_пароль
SMSC_SENDER=Globox
```

**Описание переменных:**

| Переменная      | Описание                                           | Пример        |
|-----------------|-----------------------------------------------------|---------------|
| `SMS_PROVIDER`  | Какой провайдер использовать (`stub`, `smsru`, `smsc`) | `smsc`        |
| `SMSC_LOGIN`    | Логин на smsc.ru                                    | `galimov5500` |
| `SMSC_PASSWORD` | Пароль (основной или API)                           | `***`         |
| `SMSC_SENDER`   | Имя отправителя (зарегистрированное)               | `Globox`      |

### Шаг 7. Тестирование

1. Установите `SMS_PROVIDER=smsc` в `.env`
2. Перезапустите API-сервер:
   ```bash
   pm2 restart marketplace-api
   ```
3. Попробуйте зарегистрироваться через телефон на сайте
4. Проверьте логи API:
   ```bash
   pm2 logs marketplace-api --lines 20
   ```
5. Вы должны увидеть:
   ```
   SMS отправлено на +79XXXXXXXXX через SMSC.ru, id=..., cnt=1, cost=...
   ```

## Режимы работы SMS

В проекте поддерживается 3 провайдера. Переключение — через `SMS_PROVIDER`:

| Значение | Описание                                           |
|----------|-----------------------------------------------------|
| `stub`   | SMS **не отправляются**, код виден только в логах API. Для разработки. |
| `smsru`  | Отправка через SMS.RU (api_id в `SMS_API_KEY`)     |
| `smsc`   | Отправка через SMSC.ru (логин/пароль в `SMSC_*`)   |

## Лимиты и ограничения SMSC.ru

- **Лимит отправки** — настраивается в разделе **Лимиты и ограничения** (https://smsc.ru/limits/)
- Рекомендуется установить лимит по IP и по количеству SMS в минуту для защиты от злоупотреблений
- При отрицательном балансе SMS не отправляются — сервис вернёт ошибку
